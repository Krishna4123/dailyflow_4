# DailyFlow — Workshop Starter

This is the starter repository for the **Build DailyFlow with Kiro** 5-hour workshop.

Follow the workshop guide your instructor provided. Do not implement anything manually — use Kiro for all code generation.

## Quick start

```bash
npm install
npm run dev
```

- API: http://localhost:3001
- Web: http://localhost:5173
- Health check: http://localhost:3001/health

## What's already here

- Full-stack application scaffold (`backend`, `frontend`)
- TypeScript strict mode configured everywhere
- SQLite database setup with Express backend
- React + Vite frontend with tab navigation
- Health check: http://localhost:3001/api/v1/health
- Tasks, reminders, habits, score, and export features

## What you will build with Kiro

Everything else. Follow the phases in your workshop guide.
